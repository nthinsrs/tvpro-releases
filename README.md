# 1TV releases

Release files for 1TV, an IPTV and media player for Windows, Android phones and Google TV.

Install the latest version:

- Android phone or TV: https://github.com/nthinsrs/1tv-releases/releases/latest/download/1TV.apk
  (on a TV with the Downloader app, enter the code **8574295**)
- Windows: https://github.com/nthinsrs/1tv-releases/releases/latest/download/1TV.exe

Installed copies check `releases/latest/download/1tv-update.json` and update themselves.

Privacy policy: [PRIVACY.md](PRIVACY.md). Contact: onetv.support@gmail.com

This repository holds release files only.
